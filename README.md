# 🛡️ SaveHer AI
> AI-Powered Women & User Safety Platform

Built for **Google Solution Challenge 2026** — Rapid Crisis Response track.
Team: Zulfikar | Maharana Pratap Engineering College, Kanpur

## 🚀 Features
- AI Harassment Analyzer (Gemini 1.5 Flash + Tesseract.js OCR)
- Auto Legal Complaint Generator (IPC, BNS 2023, IT Act 2000)
- SOS Emergency System with Live GPS + Nearby Police & Hospitals
- Digital Signature Canvas + PDF Export
- National Cyber Crime Helpline 1930 Integration
- Firebase Auth (Email + Google OAuth)

## 🔧 Tech Stack
Next.js 16 · React 19 · TypeScript · Tailwind CSS 4
Firebase Auth + Firestore + Hosting · Google Gemini 1.5 Flash · Tesseract.js

## ⚙️ Local Setup

1. Clone the repo
   git clone https://github.com/[USERNAME]/saveher-ai.git
   cd saveher-ai
   npm install

2. Create .env.local file with your keys:
   NEXT_PUBLIC_FIREBASE_API_KEY=your_key
   NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_domain
   NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
   NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_bucket
   NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_id
   NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
   NEXT_PUBLIC_GEMINI_API_KEY=your_gemini_key

3. Run locally:
   npm run dev
